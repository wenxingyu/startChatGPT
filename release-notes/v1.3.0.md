新增 macOS 启动器和原生菜单栏额度显示，提供 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台的下载。

## 新增

- macOS 自动查找 `/Applications` 和 `~/Applications` 中的 Codex、ChatGPT，优先启动 Codex；也可通过 `STARTCHATGPT_APP_PATH` 指定应用位置。
- 原生 AppKit 代理设置窗口，支持保存代理、直接连接，以及 `--proxy=...`、`--no-proxy` 临时覆盖；设置保存在 `~/Library/Application Support/startChatGPT/config.txt`。
- macOS 菜单栏显示短期剩余额度，可查看两个额度周期和本地时区的重置时间，支持手动刷新和每 45 秒自动刷新；读取失败时保留旧数字并标记过期。
- 支持 `--usage-only` 独立显示额度和 `--usage-widget` 额度小窗；重复启动不会新增菜单栏图标，正常启动模式下桌面端退出后额度显示也会退出。
- macOS 可查找 Homebrew、npm、PATH 和桌面端内置的 Codex CLI，包括嵌套 CodexCLI.app 布局；也可通过 `STARTCHATGPT_CODEX_EXE` 指定 CLI。
- GitHub Actions 分别构建 Windows x64、macOS Apple Silicon 和 Intel 安装包，并提供 SHA-256 校验文件；发布页自动使用仓库中的版本说明。

## 调整

- Windows 和 macOS 共用代理配置、启动参数解析和额度读取逻辑，保留 Windows 的应用包激活、启动动画和系统托盘功能。
- macOS 启动桌面端和读取额度时使用所选代理；直接连接时清理继承的代理环境变量。已运行的桌面端会提示先退出后重新启动，以应用新设置。

## 验证与限制

- 发布流程在 Windows x64、macOS Apple Silicon 和 Intel 上运行 Rust 测试与构建；macOS 额外检查 Rust 格式、运行 Swift 原生组件自检和应用签名校验。
- macOS 版处于适配验证阶段，编译和自检不能代替桌面端界面及实际代理流量的实机验证。完整检查步骤见 [macOS 验证清单](https://github.com/wenxingyu/startChatGPT/blob/v1.3.0/docs/macos-testing.md)。
- Windows 可执行文件尚未签名；macOS 应用仅有本地 ad hoc 签名，尚未进行 Developer ID 签名和公证，首次打开可能需要在系统设置的“隐私与安全性”中允许。
- 启动器最低要求 macOS 11；目标桌面应用仍需满足其自身的系统和架构要求。macOS 暂不提供 Windows 的启动动画和 Shift 双击设置入口。

## 下载与升级

- Windows x64：下载 `startChatGPT.exe`，退出旧版启动器和额度显示后替换运行，已有代理配置会保留。
- macOS Apple Silicon：下载 `startChatGPT-macos-aarch64.zip`。
- macOS Intel：下载 `startChatGPT-macos-x86_64.zip`。
- macOS 解压后将 `startChatGPT.app` 放入 Applications。首次使用默认代理为 `http://127.0.0.1:10808`；修改设置可运行 `"/Applications/startChatGPT.app/Contents/MacOS/startChatGPT" --settings`。
- 额度读取需要本机可运行且已登录的 Codex CLI，并与桌面端使用同一账户；不会创建模型任务或读取、复制、记录登录令牌。
- 下载后可使用 `SHA256SUMS.txt` 校验文件完整性。
