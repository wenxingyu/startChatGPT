本次更新修复 macOS 应用图标，并将 macOS 启动目标调整为 ChatGPT。

## 修复与调整

- 修复 macOS 应用显示默认空白图标的问题：应用包加入 ChatGPT 图标，并在 Info.plist 中声明图标文件。
- macOS 自动查找 `/Applications/ChatGPT.app` 和 `~/Applications/ChatGPT.app`，直接启动 ChatGPT，不再查找或优先启动 Codex.app。找不到 ChatGPT 时会给出明确提示；自定义安装位置仍可通过 `STARTCHATGPT_APP_PATH` 指定。
- 更新桌面端已运行时的提示、使用说明和 macOS 验证清单。
- Swift 编译缓存改为存放在项目构建目录，避免默认缓存目录不可写时构建失败。

## 下载与升级

- Windows x64：下载 `startChatGPT.exe`。
- macOS Apple Silicon（M 系列）：下载 `startChatGPT-macos-aarch64.zip`。
- macOS Intel：下载 `startChatGPT-macos-x86_64.zip`。
- macOS 退出旧版启动器和额度显示后，解压 ZIP，用新的 `startChatGPT.app` 替换 Applications 中的旧版，已有代理设置会保留。
- macOS 修改代理设置：在终端运行 `"/Applications/startChatGPT.app/Contents/MacOS/startChatGPT" --settings`。保存并启动前，请先完全退出正在运行的 ChatGPT。
- macOS 应用尚未完成 Developer ID 签名和公证；首次打开若被系统拦截，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。
- 额度显示仍需要本机可运行且已登录的 Codex CLI。下载后可使用 `SHA256SUMS.txt` 校验文件完整性。
