本次更新按 Rust 模块职责重新组织代码，改善 Windows、macOS 和共享额度服务的维护边界。

## 重构与调整

- 平台启动与原生界面集中到 `platform/windows` 和 `platform/macos`，主程序入口只负责调用平台入口。
- 额度模块拆分为额度数据与响应解析、Codex CLI 查找、app-server 进程通信、后台刷新与故障恢复，平台界面通过统一接口使用额度服务。
- Windows 窗口消息通知移到平台层；主窗口检测与进程退出等待从启动动画中提取为独立模块，供启动流程和托盘共同使用。
- macOS 应用查找、启动流程、Swift 界面通信和额度事件转发分别组织，便于独立维护。
- 收紧内部模块可见性，使用 Rust 默认的模块文件查找规则组织恢复测试，并新增代码结构说明。

## 兼容性与验证

- 保留现有命令行参数、代理配置格式、额度刷新与重连逻辑、二进制名称和 Swift 界面通信协议；升级后继续使用已有代理设置。
- 保留两个平台原有的全部 22 个测试函数；本地 macOS 验证通过 11 项测试，另 1 项为测试专用子进程入口，保持 ignored。
- 本地通过 Rust 格式检查、macOS 编译检查，以及 Apple Silicon 和 Intel 两种架构的 Release 构建。
- 发布流程继续在 Windows x64、macOS Apple Silicon 和 Intel 上运行测试与构建；macOS 同时执行原生组件自检和签名校验。

## 下载与升级

- Windows x64：下载 `startChatGPT.exe`，退出旧版启动器和额度显示后替换运行。
- macOS Apple Silicon（M 系列）：下载 `startChatGPT-macos-aarch64.zip`。
- macOS Intel：下载 `startChatGPT-macos-x86_64.zip`。
- macOS 退出旧版启动器和额度显示后，解压 ZIP，用新的 `startChatGPT.app` 替换 Applications 中的旧版。
- 额度显示仍需要本机可运行且已登录的 Codex CLI。下载后可使用 `SHA256SUMS.txt` 校验文件完整性。
- Windows 可执行文件尚未签名；macOS 应用仅有本地 ad hoc 签名，尚未完成 Developer ID 签名与公证。
