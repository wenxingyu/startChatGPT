修复 Windows 11 上更新 ChatGPT 后，通过启动器打开时出现“ChatGPT failed to start / 该进程没有程序包标识符”的问题。

## 修复

- 通过 Windows 应用激活接口启动已注册的 ChatGPT 应用包，并继续传递代理和其他命令行参数。
- 优先读取当前用户注册的应用包及其清单，避免选中 WindowsApps 中更新后残留或尚未注册的版本目录。
- 正确处理参数中的空格、引号、反斜杠和中文。

## 验证

- 本地 17 项自动化测试通过，包括 Windows 命令行解析器的参数往返验证。
- 在已安装 ChatGPT 的 Windows 环境中，实际应用激活和主窗口检测通过。
- 本次实机验证唤起了已运行的 ChatGPT，未覆盖关闭后首次启动时的代理生效情况。

## 升级

退出旧版启动器和额度托盘，替换 `startChatGPT.exe` 后重新运行。已有代理配置会保留；如需更换正在运行的 ChatGPT 的代理，请先退出 ChatGPT。

附件为 GitHub Actions 构建的未签名 Windows x64 可执行文件，并提供 `SHA256SUMS.txt` 校验文件。
